# الأيقونات (Iconography) — زراعي برو

## أ. App Icon الرسمي

الأيقونة الرسمية للتطبيق (`brand-assets/app-icon/`) هي اقتصاص مباشر من
الصورة المرجعية — مربع بحواف دائرية، خلفية داكنة صلبة، إطار أخضر فاتح
رفيع، ويحتوي رمز الترس + الجرار + السهم + خطوط الحقل بنفس الألوان
والتدرجات الأصلية.

### المقاسات الجاهزة

| المقاس | الملف | الاستخدام |
|---|---|---|
| 1024×1024 | `app-icon-1024.png` | App Store / Google Play (المصدر الأساسي للتصدير) |
| 512×512 | `app-icon-512.png` | PWA manifest (`icon-512`) |
| 256×256 | `app-icon-256.png` | أيقونات سطح المكتب / اختصارات |
| 128×128 | `app-icon-128.png` | PWA manifest (`icon-192` نطاق قريب) / قوائم تطبيقات |
| 64×64 | `app-icon-64.png` | أيقونات صغيرة داخل الواجهة |
| 48×48, 32×32, 16×16 | `brand-assets/favicon/` | Favicon المتصفح |

جميعها ناتجة عن **تصغير (resize) بسيط** لنفس الأيقونة الأصلية — لا رسم
جديد ولا تبسيط في التفاصيل.

### قواعد صارمة

- **لا تغيير** في: الألوان، التكوين، الترس، الجرار، الأسهم، الخلفية، أو
  النسب — الأيقونة تُستخدم كما هي في كل سياق.
- لا تُضاف حواف/ظلال/تأثيرات جديدة غير الموجودة أصلاً في الصورة المرجعية.
- عند الحاجة لخلفية شفافة (مثل بعض متطلبات الأندرويد Adaptive Icons)
  يُستخدم القرار من قِبل فريق التطوير عند التنفيذ الفعلي — هذا التوثيق لا
  يُنشئ تلك النسخة الآن لتجنّب اختراع أصل جديد لم يكن موجودًا.

## ب. أيقونات واجهة المستخدم (UI Icons)

هذه القواعد لأي أيقونات وظيفية تُستخدم داخل شاشات التطبيق مستقبلاً (غير
اللوجو نفسه) — للحفاظ على اتساق بصري مع لغة اللوجو:

| الخاصية | القيمة |
|---|---|
| **Style** | Outline / Stroke-based بسيطة (minimal line icons)، وليست Icons مصمتة معقدة |
| **Stroke Width** | ثابت عبر كل الأيقونات (مثلاً 1.5–2px بمقياس 24×24) |
| **Size** | نظام مقاسات ثابت: 16 / 20 / 24 / 32px |
| **Corner Treatment** | زوايا مستديرة خفيفة (rounded joins/caps) — تتناسق مع الحواف الدائرية لمربع الـ App Icon |
| **Active State** | اللون Primary/Secondary Green (`#8CFF00` أو `#22C55E`) أو تعبئة خفيفة |
| **Inactive State** | اللون Neutral (`#64748B`) بدون تعبئة |
| **Disabled State** | نفس شكل Inactive بشفافية أقل (opacity ~40%) |

### مبادئ عامة

- **Minimal**: لا تفاصيل زائدة داخل الأيقونة الواحدة.
- **Modern**: خطوط نظيفة، لا زخرفة كلاسيكية.
- **Professional**: لا أيقونات كرتونية أو "cute".
- **Consistent**: نفس سُمك الخط ونفس زاوية الزوايا عبر كل مكتبة الأيقونات.

> ملاحظة: هذا القسم توجيهي لأي عمل تصميم مستقبلي على أيقونات الواجهة —
> **لا يُطبَّق تلقائيًا على مكتبة الأيقونات الحالية في التطبيق**
> (`src/components/ui/Icons.jsx`)، والتي لم تُمس ضمن هذه المهمة.
